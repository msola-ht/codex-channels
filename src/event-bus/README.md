# Event Bus

本目录提供进程内有界事件传递，隔离 App Server Reader 与 Telegram 等慢速消费者。

## 文件

- `index.ts`：本模块的公开导出入口。
- `bounded-queue.ts`：支持非关键事件容量限制、关键事件保护、优先交互、关闭和异步消费的队列；优先项
  排在所有既有关键项之后、尚未执行的非关键项之前，两类既有项各自保持原顺序；
  可选硬上限模式在无可替换中间项时明确返回拒绝，由拥有者处理交接失败；`remove` 按值身份移除被明确取消的排队项，保留其他项的顺序与容量计数。
- `event-bus.ts`：管理订阅者及其独立队列，并隔离消费者异常；关闭后拒绝新订阅，并发关闭等待
  同一批消费者，默认最多等待 5 秒。`subscribeImmediate` 只用于同步本地可靠接纳，不能执行平台网络。

队列过载时可替换或丢弃非关键中间事件。生产 Gateway 的输入、输出 EventBus 使用硬上限与关键溢出回调：
溢出写入独立日志的故障标记，阻止新普通输入，要求按 App Server 权威状态核对，不宣称完整无损重放。
Surface 平台输出队列也使用硬上限，失败反馈给持久交接处理器。未提供故障拥有者的独立 EventBus 保留原有关键保护模式，
首次溢出及积压翻倍时告警。新增后台消费者必须明确取消、限时关闭及关键溢出的处理责任。
