# Model Relay

独立模型 API 入口的身份、准入和请求生命周期模块，不依赖 App Server、Thread、Turn 或数据库。
由 Runtime 的独立服务入口组合；生产运行验收与跨平台实机验收仍需单独完成。

- `index.ts`：公开模块能力。
- `admission.ts`：内存身份快照、常数时间秘密哈希比较、全局令牌桶与并发许可、有界上传/等待预算及按 Key 公平调度、撤销和关闭。
- `server.ts`：默认回环、可显式 IPv4 局域网监听的 HTTP、异步准备后复核、Key 精确模型授权及公共 ID 映射、逐模型思考策略和 CLP 共用请求快照。CLP Flash 快照通过 Provider Proxy 公共投影限定 DeepSeek 路由，标准快照不固定路由；原生 Chat/Responses JSON/SSE 交付及指标合同保持独立，错误只提供受控原因、阶段、上游状态和关联编号。
- `metrics-sender.ts`：有界单次指标发送、四类确认结果、零重试与限时关闭。

Runtime 注入已验证的配置、Provider 材料与网络目标；本模块不解析账户文件或凭据路径。
模型期限使用 Provider Proxy 公开的 `ModelRequestTimeoutError`，保留原准入 `phase`，另用 `timeout_stage` 标识具体超时阶段；上传返回 408，其余本地模型阶段期限返回 504。排队仍使用准入层的 429 合同，已收到的上游错误状态不被错误正文读取失败改写。直接模型适配器与 Chat 桥共用 JSON/SSE 媒体类型和 identity 响应编码校验。
HTTP 上游状态与 Relay 对外状态分别解释：上游 429/503/504 保留、408 映射 504，其他 HTTP 错误返回 502，避免把 Relay 自有上游凭据失败当作调用方身份失败。超时阶段通过采集器写入既有转储 `errorScope`，`deliveryStatus` 与模型完成状态分别保留；指标数据库不扩展。
请求收尾由 Server 从协议观察器计算一次最终模型结果，并同时交付指标与转储；采集器的 `done()` 仅记录终态到达时间，不独立推断成功或失败。生成完成后的交付失败和客户端断开保留模型完成状态，另记交付结果与对应阶段。准备取消后的迟到采集器仍通过同一收尾接口释放。
自定义 Provider 的采样默认值随同一材料快照传入，按精确上游模型 ID 在 Chat/Responses 请求缺少对应字段时补齐；调用方显式值（包括零和 null）保持原样，其他模型不继承。材料版本复核与原有授权、取消和请求大小限制保持一致。
协议验证通过 `model-api` 公共入口，网络能力通过 `provider-proxy` 公共入口。指标仅通过注入端口
送往 Gateway 单写者，不生成 Core 事件或渠道输出。
请求指标的可空 `upstreamUrl` 只在实际模型 HTTP 请求提交后从出站请求读取，保存最后一次已提交目标的 Origin 与路径；不保存用户信息、查询参数或片段，不从当前 Provider 配置回填历史。Chat 与 Responses 共用直接发送点，转储关闭时仍采集。
Relay 只转发外部调用方自带的响应报文，不归一化 Codex 私有输入项（`agent_message`、`encrypted`
参数标记）；Codex CLI 的子代理流量经 App Server 的 Provider Proxy，不经过 Relay。

模型请求与 App Server 代理共用 `runtime/model-request-policy.mjs` 的纯阶段预算：准备 30 秒、真实出站首响应头 300 秒、完整 SSE 数据事件空闲 300 秒、非流式 JSON 完整读取 300 秒、错误正文 5 秒；生成没有总期限。交付受阻最多 30 秒，终态或失败交付最多 5 秒，取消/断连/撤销会清理等待并释放准入租约。完整事件等待不因注释或零碎字节续期，也不把下游背压计为上游空闲。策略独立于凭据材料 revision；更新程序后重启 Relay 生效，不借材料热更新修改在途请求的计时。

等待队列仅在内存中：上传/等待最多 32 个、正文预算 16 MiB、排队最多 30 秒；取消/撤销/关闭
释放等待资源，不自动重放。等待不占执行许可，不生成上游指标；diagnostics 提供无正文的计数；queueSnapshot 只读返回最多 64 个当前已鉴权模型请求的身份、Provider、模型、入站思考等级、协议、阶段和耗时，完成、失败、取消或关闭后移除，不保存正文和历史。思考等级从已验证请求投影，保留 1–64 字符且不含控制字符的字符串，缺失、尚未解析或形状不可展示时为 null，不推断默认值或后续 Key 策略结果。`queueChanged` 注入端口在请求加入、阶段切换和移除时通知服务组合层，不等待网络订阅者。

`ModelRelayServer` 可注入按协议选择的独立采集器，由服务组合层按全局设置选择采集级别，提供入站快照和实际交付观测；异步初始化接收请求取消信号，完成后仍在实际出站前复核授权；未启用时不采集正文；请求指标仍独立采集上游返回的受限诊断摘要，V2 定位只在转储存在时附带。Chat JSON/SSE 保存路由及结束原因，Chat/Responses 保存有证据的错误阶段和内层错误；客户端交付失败及请求取消不冒充上游错误阶段。
旁路脱敏、容量与文件生命周期归 provider-proxy 公共能力，Relay 不操作指标数据库。

运行时诊断通过准入队列的 `oldestWaitMs` 和 `timedOut` 暴露等待时长及当前进程超时累计，不保存排队请求历史或正文；取消与撤销不计为超时。

删除身份由持久历史摘要覆盖后，准入器释放其旧凭据快照；摘要只保留身份与代次用于禁止复活，不授予调用权限。摘要移除或代次倒退会拒绝热应用；没有持久摘要覆盖的删除仍保留原内存撤销保护。
