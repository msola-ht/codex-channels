## 第一版目标与范围

统一入口和可复用流程，解决模型管理分散、托管模型在 WebUI 缺少移除入口的问题。
保留现有目录格式、账户和凭据机制，不重做整套模型生命周期。

不新增模型数据库、选择记录、禁用名单或目录版本，不引入跨数据库事务、
自动引用迁移、Relay 空授权或自动模型替换。不支持的操作显示原因，不用统一按钮掩盖差异。

| 类型 | 第一版能力 | 影响与限制 |
| --- | --- | --- |
| 自定义模型目录的 Responses/Chat 接入 | 集中已有添加、编辑、默认选择和移除能力 | 当前提供商；Relay 共用目录时也受影响 |
| CCG、OCG | 接入已有模型选择、手动添加和模板导入；WebUI 增加本地移除 | 同类全部共享账户、聚合及使用该目录的 Relay；不新增任意能力编辑器 |
| CLP Codex | 统一列表和默认选择，增加不联网的本地移除，保留显式联网更新 | 全部 CLP 账户的 Codex 共享目录与聚合；独立 Relay 目录不变 |
| DeepSeek | 展示现有模型和已有设置入口 | 暂不开放单模型移除，避免破坏模板来源和上下文跟随 |
| 使用官方共享目录的第三方接入 | 展示目录和已有默认设置 | 暂不提供单接入裁剪，不修改共享官方源文件 |
| CLP Relay | 保留独立目录查看、更新和 Key 管理 | 本次不新增模型删除或选择策略 |

官方 OpenAI 登录态接入不在本次范围。连接和账户继续使用既有接入入口；
配置完成后从模型管理入口操作。模型移除不要求重填 Key、不删除账户、不改变地址或协议。
现有全局上下文设置保留独立入口和完整影响预览，不能伪装成当前提供商的单模型编辑。

## 入口与身份

WebUI 保留提供商接入、账户与凭据、模型管理的职责划分。
模型列表展示精确 ID、提供商或共享账户组、默认使用情况及允许的操作。
共享目录呈现一份编辑目标；从 `clp-main` 进入也必须说明影响全部 CLP 账户。

操作以精确提供商或受支持共享组加模型 ID 定位，由后端解析已有路径。
不接受客户端路径，不使用显示名定位；聚合 slug 和 Relay 公共 ID 通过既有规则映射，
不能直接作为目录删除键。独立目录不因模型同名联动删除。

第一版不建立源目录、策略目录、有效目录三层存储。现有保存目录就是启用集合；
需要额外策略才能隔离的官方共享目录和 CLP Relay 删除不在本次范围。

## 统一操作流程

选择操作 → 预览 → 确认 → 锁内复核 → 备份与保存 → 回读和生效提示。

1. 读取当前目录和相关账户，返回真实支持的操作；不支持的操作解释原因。
2. 预览列出模型变化、共享账户、默认冲突、Relay 联动、备份与生效要求。
   本地移除不联网、不探测模型、不要求新凭据。
3. 复用[管理接口安全](management-interface-security.md)中的认证、Origin、
   会话绑定确认令牌、修订和审计合同。输入或相关状态变化后重新预览。
   WebUI 模型编辑携带打开编辑器时的资源修订，首次预览也拒绝覆盖外部变更；CLI 在编辑结束后复核原目录。
   模型操作审计使用提供商与完整模型 ID 的有界指纹，兼容合法的长模型 ID。
4. 使用现有 Provider 管理锁，复核目录、账户、Profile、来源文件及相关默认设置。
   必需文件缺失、损坏或修订变化时拒绝；不能只比较页面可见字段。
5. 只修改目标目录及必要来源信息，保留连接、凭据、其他模型参数和账户默认值。
   回读确认保存结果；断连或回读失败不自动重试写入。

管理编排保留在 scripts，解析与文件访问使用 runtime。CLI/WebUI 共用变更计划与应用函数，
不将没有预览修订合同的交互式 callback 直接作为 WebUI API。
Application/Core 不读取管理文件路径，不引入通用插件框架。

## 移除规则与已知影响

| 情况 | 第一版行为 |
| --- | --- |
| 当前目录任一账户默认模型 | 阻止移除，先改默认值；保护全部共享账户 |
| 最后一个启用模型 | 阻止移除，沿用非空 Codex 目录合同；整体移除走账户或提供商入口 |
| 读取到 Gateway 显式默认引用 | 拒绝本次移除，按实际提供商解析，不按裸模型名跨目录阻断 |
| 旧会话或计划任务 | 保留记录，提示可能无法继续执行；沿用使用时检查，不做全局引用事务 |
| Relay Key 授权 | 不自动清空；共用目录移除后调用受目录限制，恢复模型可能重新满足旧授权，确认页必须提示 |
| 显示分组、指标、转储 | 不删除或迁移，不清理其他提供商的同名数据 |
| 全局上下文与模板 | 不扩大局部编辑范围，不删除 DS 源模板；已有全局操作单独预览 |

Provider 锁不协调全部 Gateway 配置、任务存储或外部手工修改。
第一版保护提交时可复核的状态，不承诺之后不会出现新的失效任务或配置引用；
调用仍按原有检查报错，不静默换模型。不将“未做全局扫描”展示为“没有引用”，
也不把必需目录或默认配置读取失败当作无引用。

保留 Relay 授权是明确取舍，避免引入空授权 Schema 或强制销毁 Key。
永久撤销访问应通过既有 Key 管理修改授权或撤销 Key，模型移除不是凭据撤销。
CLP Codex 移除不影响其独立 Relay 目录，该模型仍可能通过 CLP Relay 调用，预览必须写明。

## 保存、更新与重新添加

- 自定义目录：移除精确目标定义并按原生成器编译，保留默认值和其他模型能力。
  添加、编辑复用现有能力与探测约束，不通过移除重写整个连接配置。
- CCG/OCG：复用账户检查、默认保护、合法 ID/能力校验、Codex 目录校验和备份。
  手动添加与模板导入继续显式选择，不在本地移除中刷新模板。
- CLP：只裁剪当前目录，保护全部账户默认值，保留剩余能力和来源提交信息。
  目录与 manifest 一致，核对 Flash 移除后的 DS 跟随标记；
  不套用 CCG 的 `user-configured` manifest 而丢失 CLP 来源语义，按现有格式调整必要字段。
- 列表继续从保存目录派生，聚合文件可重建，不另存一份可写模型清单。

移除不是可随时一键撤销的停用。自定义模型从备份或重新填写定义恢复；
CLP 通过显式更新和选择重新导入，CCG/OCG 通过已有导入或添加入口恢复。
不建立回收站，不承诺后续编辑后仍保存所有被删定义。

联网更新以当前启用集合为初始选择，新增或曾移除项须明确选择才加入；
程序升级和重启不自行补齐目录。现有更新入口若不满足，应在实现范围修正，
不新增禁用数据库补偿；恢复不能凭空推断已缺失的自定义能力。

## 生效、备份与恢复

保留 HTTP、Responses WS、Chat 桥和聚合下游已有目录复核，旧 ID 请求返回受控错误。
实现需观察实际调用，不能仅凭列表消失证明生效，也不承诺撤销已完成准入的全部在途请求。
目录展示和 App Server 能力刷新沿用原生命周期，分别报告“已保存”和“需要重启”，
保存不自动重启或终止共享 App Server。

共用目录的 Relay 会读取变更材料，当前修订变化可能撤销整个提供商旧租约，见
[材料发布](../runtime/model-relay-service.mjs)与[准入撤销](../src/model-relay/admission.ts)。
第一版如实提示，不增加按模型取消机制。

复用现有私有文件、备份、快照检查和适用的 pending/恢复机制，不改磁盘 Schema，
不新增初始化或迁移。现有多文件恢复不等于崩溃原子事务。
实施时核对新增 CLP 本地路径各写入点与回滚，失败保留原文件或恢复依据，结果不确定停止后续操作。
恢复前检查修订，不用整份旧目录盲目覆盖后续修改；缺少必要保护时局部补齐或暂不开放操作，
不扩展为全局事务系统。不清理历史备份和凭据，也不新增旧版本兼容承诺。

## 实施与验收

1. 整理目录能力和共享范围，补齐可预览、可复核的变更计划。
2. 复用自定义、CCG/OCG 保存能力，补充 CLP 本地移除和现有默认保护。
3. CLI/WebUI 接入同一流程，清理重复实现；保留全局上下文及不支持来源的明确边界。
4. 核对更新、实际出站、聚合、Relay、回读和恢复，再更新用户文档及模块索引。

实施使用真实操作与异常输入观察，不新增或修改测试文件、guard 或变相验证脚本：

- 两入口预览一致；默认模型、最后一个模型、错误 ID、过期预览和损坏目录拒绝且文件不变。
- 共享账户与同名独立模型的影响正确，本地移除不依赖上游网络、不改变凭据。
- CLP Flash 与其他模型移除后 manifest 一致，独立 Relay 目录保持原语义。
- 重新打开、重启、显式更新不意外加回模型，重新加入需明确选择。
- HTTP、WS、Chat 桥、固定/切换、聚合及共用目录的 Relay 执行原有拒绝规则。
- 旧会话和任务不自动换模型，Relay 保留授权及重新加入后的行为符合提示。
- 备份、失败回读、中断和恢复冲突可诊断；Windows ACL 与 Unix 权限保持业务约束。

Linux 隔离目录中已观察 CLI 与真实 WebUI 的自定义模型移除、WebUI 纯模型编辑与回读；
不同提供商的同名模型不联动删除。CLP 两账户共享目录移除 Flash 后保留来源提交和下载时间，
manifest 退出 DS 跟随；原目录备份保留。过期预览、其他账户默认模型、错误 ID 及损坏目录被拒绝，且拒绝路径未修改原目录。
CCG/OCG 双账户共享目录已观察成功移除及最后一个模型拒绝；模型专用编辑已观察保留完整连接块和显式超时配置。
实际 HTTP Responses 和 CLP Chat 桥对已移除 ID 返回 409。
后续关联审查补齐固定模式原配置校验、编辑读取修订与有界审计目标；隔离操作已观察不受支持的固定配置被拒绝、缺少编辑修订返回 409、隐式移除和候选缺失被拒绝，以及 200 字符模型 ID 的审计记录成功写入。
WS 长连接、聚合重建、Relay 在途撤销和 Windows/macOS 文件权限恢复目前仅完成源码关联审查，
未作对应运行观察；不将静态检查和 CI 作为这些路径的行为证据。
