## 已观察的路径与反例

实施环境为 Linux、原生 Codex 0.164.0；动态官方合同与锁定源码均已查阅。除公开模型元数据外，网络行为使用隔离配置、虚拟 Key 和本地合成上游。以下记录是实际执行结果，不是静态检查推断：

- 公开发现实际取得 23 模型，其中 11 候选、11 待确认、1 排除；两次完整读取为 54 元数据请求，零认证/推理。这个数量是当日快照，不保证未来目录不变。
- 账户及模型入口通过真实配置 writer 保存，CLI 与 WebUI 后端/浏览器交叉回读。未选账户、模型和 Profile 保持；取消及无变化不写入，竞争修改使旧预览失效；账户 Key 替换后旧验证不能继续收费。
- 单模型新增实际通过两级六请求诊断、保存和目录回读。畸形 SSE envelope、工具完成项缺失/冲突、错误 usage/phase/metadata、仅 JSON 快照和容量不足不能生成可保存的 verified 结果。64 模型目录在付费前阻断；总诊断期限实际约 90002ms 停止且仅一请求。
- 原生 `apply_patch` 在合成上游下实际创建、修改含中文和补充平面字符的文件并续答；Proxy/Relay 的 JSON/SSE 均观察。半帧、非法 UTF-8、超限、未完成工具、身份/输入冲突及取消均受控处理，没有把坏补丁作为完整工具交付。
- 搜索设置中 CLI 保存 beta live，浏览器读到同一值，随后从 WebUI 确认改为 disabled；runtime/startup 读取一致，alpha 和目录未变。截图 `output/playwright/ollama-search/settings-live.png` 已查看，最终夹具 beta 为 disabled。
- 搜索四条 HTTP 组合（Proxy/Relay × JSON/SSE）正常完成两模型轮和一次搜索；原生 CLI 显示搜索 started/completed、摘要答案及 turn.completed，exit 0。混合客户端调用不执行，freeform 历史保持单层包装，缺 Token 数时未伪造计数。
- 401 搜索原先触发原生两模型轮/两搜索及重连；修复后只一模型轮/一搜索，直接 turn.failed，没有失败搜索完成项。cached/indexed/过滤等七类不支持控制在零出站时拒绝；超限摘要、伪造搜索、工具选择违约、耗尽/未知预算均阻断。
- 搜索实际 45008ms 超时，无自动重试；短整体期限、真实客户端断连、Relay 租约撤销和 refresh 内停止监听均停止后续工作并释放自有连接。未等待完整十分钟。freeform 包装后 4,800,708 字节的输入从原先一请求改为零出站；累计预算阻止第二模型轮。交付中途取消原先序号 0/1/2/3/8，修复后两个 owner 及撤销反例均 0–4 连续、单失败终态。

最后一轮独立原生成功夹具为 `/tmp/olc-batch8-astra-native.JDOauu`；设置夹具为 `/tmp/olc-batch8-settings.0h2Jfa`，逐模型保存夹具为 `/tmp/olc-batch7-astra.2STBj8`。它们是任务临时材料，可能被清理，不是产品运行依赖。所有自有服务、原生进程、浏览器及异步句柄已结束。

静态工作流另行记录：第八批正常提交钩子的类型、版本、模块边界、Lint、文档索引、WebUI 构建/翻译和 Gateway 构建全部通过；i18n 为 2321 源键。没有新增或维护冻结测试，也没有创建 guard/probe 脚本。检查通过不代表云端可用。
