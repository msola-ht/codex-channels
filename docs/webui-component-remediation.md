## A 独立审查

A `astra_ui_initial_review`（`gpt-6-astra/high`）已在产品代码未变的 `304b759a` 上完成只读独立审查，确认 U01–U04 均成立。它独立追踪共享组件及模型、提供商、账户、模板、统计分组、工具设置等调用方，核对 Gateway 与 Codex 预览响应和确认消费；没有重跑浏览器，精确尺寸沿用原观察。

关联补充：U01 必须同时覆盖普通菜单项的换行；U03 还包括采样/响应参数分组、截断策略和 WebUI 令牌说明；U04 增加 P2 操作意图问题：令牌及代理清除的脱敏响应不含 `action: clear`，危险确认分支不可达；替换可能显示成“已配置 → 已配置”。应在同次预览的前端 pending 展示模型中保留白名单非秘密意图，不从状态反推，也不向格式化器传原始秘密。host 修改为公开监听时，必须保留自动生成令牌的副作用。此新增项来自源码判断，尚未在浏览器复现。

审查未发现需要改变服务器脱敏响应、确认指纹或存储格式的理由。完整读屏、所有消费者逐状态和真实保存未在该代理审查中观察；其全部命令已结束，无遗留进程或异步任务。

## 修复步骤

A 审查后确定以下实施顺序：

1. 沿共享选择框到业务表单和弹层核对布局约束，修正 U01，并观察长中文、无空格 ID、普通短标签、选项菜单和窄屏/桌面。
2. 完成 U02 的字段错误模型、输入变化失效、重试及保存预览链路；观察非法/空白/越界值到合法草稿的恢复，避免旧错误、错字段提示和未通过校验的预览。
3. 完成 U03 的模型字段/分组、截断及 WebUI 令牌说明关联，核查动态控件、复用实例和已有正确表单路径。
4. 追踪 U04 所有共享确认调用方及服务器公开响应；pending 保留非秘密操作意图，按当前受支持设置展示实际前后值和组合修改范围，保留秘密遮蔽、公开监听自动生成令牌提示及确认取消/焦点/版本门禁。
5. 构建后进行 Hack 与真实本地入口浏览器观察；记录真实数据和模拟响应的区别。运行适用静态检查，禁止新增或修改测试、guard/probe/smoke 脚本。
6. 完成后启动新的 A 独立审查最终改动和关联调用链，处理确认问题；更新现行合同与本记录状态，正常提交并收集提交门禁结果。

## 实施与复查结果

产品实现及独立复查已完成：

- U01：仅修改业务层 `ManagedSelect`，Field/标签/说明/Trigger/Value 共同约束宽度；普通值保留截断，完整菜单文字换行，Popup 限定视口宽度。保留 `items`、未知当前值、空值和禁用选项。
- U02：端口、保留天数、最大行数分别保存字段错误和被校验草稿；错误就地展示并关联控件，输入变化与成功回读分别清除本字段错误；指标同时校验两项，聚焦第一项错误，不请求非法预览。
- U03：每模型实例 `useId`；高级字段、采样/响应分组、截断选择与上限、WebUI 输入和生成令牌说明均关联到实际控件，条件渲染保持引用存在。
- U04 及 P2 关联项：Gateway adapter 仅提取白名单 `set/clear/generate`，通用版本化 Hook 在同次预览成功后保存非秘密 intent。确认按 intent 选择危险样式与动作说明，按 kind 展示范围；模型默认值、指标和偏好保留组合字段，工具保留精确路径与值，host 保留自动生成令牌副作用。原始 setting/revision/token、服务端预览、指纹、写入、回读、CLI 与 Setup 的存储合同均未修改。
- 静态状态：最终源码 WebUI 类型与生产构建、WebUI lint、2056 键中英文/占位符校验、80 份文档索引/链接校验通过。正常提交仍由既有 pre-commit 执行门禁；这些状态不证明业务可用性。
- 已观察真实临时 WebUI：端口 `70000` 聚焦字段，`aria-invalid=true`、错误关联正确；改 `8788` 后错误立即消失。取消前后配置 SHA-256 一致；重新确认保存后，WebUI 和共享配置模块均读到端口 `8788`。指标 `0/999` 同时产生两个字段错误，只改第一项保留第二项错误；合法预览保留两项值。公开 host 预览包含地址与令牌状态，明确自动生成令牌，取消后实际 host 与令牌状态保持原值。

第二个 A `astra_ui_final_review`（`gpt-6-astra/high`）独立审查完整实现差异，未发现确认阻断问题，覆盖共享组件消费者及 Gateway/Codex 的当前值、预览、pending、确认和回读链；它仅实际查看端口与令牌清除截图，没有操作浏览器。其后主代理继续浏览器回归发现 U01 菜单仍被裁切：原选择器匹配 `span`，实际 ItemText 是首个 `div`，文字仍为 nowrap，宽 672px。已在业务组合改为约束首个文字子节点，保留基础组件。

第三个 A `astra_ui_menu_final_review`（`gpt-6-astra/high`）独立复查该补充修复及 U01 相交消费者，未发现阻断问题。它核对本地 SelectItem 先渲染 ItemText 再渲染勾选，安装版 Base UI 不插入前置 DOM，当前首节点约束稳定；值/标签、空值、未知当前值、禁用与 fullWidth 保持合同。它查看更新后的长中文截图，未重测尺寸；U02–U04 沿用第二个 A 对未变输入的有效审查。基础组件未来升级若改变节点顺序，需重新核对组合样式。
