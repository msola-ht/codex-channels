## 逐链路记录

### W01 启动、鉴权与路由

- 已追踪：`main.tsx` → `consumeQueryToken` / `token-storage` → `App/AuthGate` → `Layout/navigation` → `webui-server.handleRequest/routeManagement` → `webui-http.authorized` / `management-access`。
- 源码证据：查询令牌先移出地址再保存；存储写入必须按 API 相同优先级读回成功。手动登录有 30 秒上限和卸载取消。管理路由先验证 Bearer、真实连接与 Origin，再进行限速与分派；非回环监听缺令牌拒绝启动。页面懒加载和页面错误边界保留导航恢复，非法线程路径有专门恢复界面。
- 模块结论：凭据、鉴权、导航与页面业务已分离；`AuthGate` 原始请求属于 README 明确允许的例外。布局持有共享时钟、采集开关和有限控制台状态，未发现由此直接操作后端业务资源的问题。
- 本条未确认需修缺陷。源码结论不等于浏览器登录、远程代理或移动布局已观察；真实令牌及用户服务未访问。

### W02 公共数据生命周期

- 主代理追踪：`use-api` → `api.requestResponse/requestJson/watchQueue`；`use-queue-events` → `webui-queue-events` → `runtime/queue-events`；`use-range-refresh` / `range-refresh` → `use-server-time` / `server-time`。并核对指标查询 URL 编解码与分页入口。
- 源码证据：请求带超时和取消信号；被替代或卸载的读取不提交结果。通知只带变化/心跳标记，前端逐帧限长，服务端连接数量和背压有界，断开取消私有 IPC；订阅初始变化补足快照间隙。失败补读有限重试，写入没有通用自动重试。时间驱动刷新区分滚动与日历范围，后台/离线/历史页等条件暂停。
- 共享合同注意项：`useMetricsSnapshot` 可以保留旧 `data`，查询切换由 `loading`、错误门禁和消费者共同隔离，不能单看 Hook 就判为旧数据泄漏。W04/W05 已确认请求/错误/会话页失败时隐藏数据、加载时阻断操作。控制台另以请求身份隔离，合同不同。
- 本条未确认需修缺陷。未观察真实网络断开、休眠恢复、跨日/DST、IPC 关闭与资源释放；不把源码保护写成实际运行成功。

### 每包必须保持的关联范围

- **R1：** WebUI 前台和受管启动入口、自有 CLI 及下游自有进程树、取消未确认与重复停止、Unix/Windows 适配、共享总退出预算；清理的预览/确认/实际删除用同一身份基准。不得终止独立共享服务，也不得把服务管理器兜底当作退出证据。
- **R2：** 主配置字段编辑与凭据版本发布相互协调，保留未选字段和其他账户；覆盖预览后竞争、提交未知和恢复时更新后的文件，不以备份覆盖较新修改。若设计改变用户数据/恢复语义，先补齐数据处理与回滚方案再进入对应实现。
- **R3：** 离页、换查询、客户端超时、服务停止均能到达读取所有者；返回体积限制和总扫描预算分别处理，取消不能只隐藏前端旧结果。
- **R4：** 区分未执行、提交未知、已提交但收尾失败、取消未确认；贯穿 CLI/API 到 UI，现有安全脱敏和不输出任意命令正文的边界保留。F09 翻译随受控恢复语义一起完成。
- **R5：** 已保存、激活失败和 HTTP 结果未知保持不同；一次性秘密丢失时提供核对/轮换恢复。核查共用 Hook 的任务、投递、重置券消费者，不改变其已有不同合同。
- **R6：** 默认保护由业务管理层共享判断，UI 只消费原因且后端继续锁内复核；候选 Hook 提取保留草稿、用户发起、取消、失效和费用边界，不扩成通用框架。
- **R7：** 同值 API、普通 UI、预览/执行、审计与回读使用一致的 unchanged 语义，不制造保存或重启结果；保留官方缓存已有的上游锁限制说明。
