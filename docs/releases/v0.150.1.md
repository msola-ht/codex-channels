# v0.150.1-rc.1 预发行版

`v0.150.1-rc.1` 是 Codex Connect Gateway 对应 `codex-cli 0.150.1` 的候选预发行版。它用于在
正式版前验证安装、升级、渠道运行与 App Server 兼容性，不会替换 npm `latest` 指向的当前正式版。

## 发布状态

- 发布类型：候选预发行版
- Gateway 版本：`0.150.1-rc.1`
- Codex CLI 与 App Server 协议：精确锁定 `0.150.1`
- Git Tag：`v0.150.1-rc.1`
- npm 包：`@hegenai/codexc@0.150.1-rc.1`
- npm 标签：`next`
- GitHub Release：Pre-release
- 数据库 Schema：未变化

## 新增

- `/mcp` 与 `/mcp health` 显示当前 Session 的官方 MCP 运行状态，区分连接中、已连接、需要认证、
  失败、取消、禁用和未知，并提供有界的处理建议。
- 使用官方父 Turn 子代理活动完成通知结算后台子代理结果，同一子代理连续追加任务时分别跟踪每一轮。
- 支持 `0.150.1` 新增的账户套餐、认证枚举、Skill Plugin 归属、模型生命周期提示和多代理动作状态。

## 修复

- 修复父 Turn 完成、Session 切到后台或 Gateway 延后释放订阅时，晚到的子代理成功结果可能丢失或
  重复显示的问题。
- 修复同一父 Turn、同一子代理连续执行追加任务时，上一轮完成可能提前释放下一轮跟踪的问题。
- 修复 Turn 已完成但没有最终助手消息时，渠道可能只显示处理中状态而没有明确终态的问题。
- 修复 MCP 快捷命令使用不可执行占位符的问题，改为生成带具体序号的命令。
- 修复 Doctor 的 Plugin API 提示写死旧 Codex 版本的问题，改为读取当前协议锁定版本。
- 对 `writeStdin` 和未知命令审批种类保持失败关闭，避免套用普通命令审批预览。

## 改动

- Gateway、生成协议、CI、真实 App Server 合同与固定上游源码索引统一锁定到 `0.150.1`，不保留
  旧 CLI 兼容分支。
- 用户可见的会话文案统一使用 `Session`；协议方法、生成类型和内部实现继续保留官方 `Thread` 名称。
- MCP 查询只读取当前 Session 已发布的运行快照，不把查询或刷新请求成功表述为远端握手完成。
- 子代理成功结算只采用父 Turn 的官方完成归属信号；失败和中断继续采用各自的官方异常终态。
- 随锁定 App Server 获得不可信项目、凭据脱敏、MCP 启动与 Unix 关闭、远程压缩图片 Token 预算等
  上游修复。

## 未开放的上游能力

本次生成协议包含但 Gateway 不开放 Project、Realtime、Amazon Bedrock、Browser/Computer Use、
Hosted App MCP 事件流、`writeStdin` 审批、TUI 任务引用和 Interrupt Hook。生成类型存在不代表项目
支持这些能力；采用条件与拒绝理由见
[`Codex CLI 升级决策记录`](../codex-cli-upgrade-decisions.md#01501)。

## 兼容与升级

- 必须使用精确的 `codex-cli 0.150.1`，旧 CLI 不受支持。
- 不包含数据库 Schema 迁移，不需要单独运行数据库升级命令。
- 不改变 Gateway 配置版本、Provider 凭据文件、Workspace Registry 或渠道配置格式。
- 预发行版发布后，使用精确版本安装：

```bash
npm install -g @openai/codex@0.150.1
npm install -g @hegenai/codexc@0.150.1-rc.1
codexc doctor
```

- 不建议把生产环境的自动升级入口切到 npm `next`；验证结束后可以重新安装 README 标明的正式版。

## 验证范围

- 协议版本、类型、Lint、文档与索引、全量测试、构建、npm tarball、干净源码安装和服务模板门禁。
- `codex-cli 0.150.1` 真实 App Server 合同，包括 MCP 状态、资源、审批、账户枚举和子代理完成顺序。
- Linux 与 macOS CI，以及 Gateway、App Server、Doctor、MCP 和多轮子代理部署冒烟。

## 正式发布边界

预发行版必须在已合并且 CI 通过的 `main` 上按
[`Codex CLI 升级流程`](../codex-cli-upgrade.md#5-正式发布)执行：README 先显示精确 RC 与安装命令，
发布检查通过后再创建 `v0.150.1-rc.1` Tag。npm Trusted Publishing 成功后才能创建同版本
GitHub Pre-release。正式版继续使用新的 `v0.150.1` Tag 和 npm `latest`，不得移动 RC Tag 或覆盖
已经发布的 RC 包。
