# v0.148.0-fix2 修复预览版

`v0.148.0-fix2` 是 `v0.148.0-fix1` 的源码更新热修版。它不升级 OpenAI Codex CLI 或 App Server
协议，仍要求精确的 `codex-cli 0.148.0`。

## 发行渠道

- npm 包：`@hegenai/codexc@0.148.0-fix2`
- npm 标签：`fix`
- Git Tag：`v0.148.0-fix2`
- `latest`：仍保持 `0.148.0`。

## 新增

- 无。

## 修复

- 修复 `codexc update` 克隆修复版 main 后报“源码 package.json 缺少正式版本号”的问题。
- 源码更新器现在接受与锁定 Codex CLI 基础版本一致的 `-fixN` Gateway 版本，并按修复序号判断
  升级与降级。
- 候选源码的 Codex CLI 校验改为读取 `src/codex-protocol/version.json`，不再把 Gateway npm
  包版本误当作 Codex CLI 版本。

## 改动

- Gateway 包版本和运行时版本更新为 `0.148.0-fix2`；协议继续保持 `codex-cli 0.148.0`。
- npm `fix` 标签由 `0.148.0-fix1` 前移到 `0.148.0-fix2`，`latest` 不变。

## 安装与恢复更新

由于旧源码更新器无法自行越过 `-fixN` 版本预检，受影响的源码安装需要先更新全局命令：

```bash
npm install -g @hegenai/codexc@0.148.0-fix2
codexc update
```

更新成功后，源码应切换到当前 main，随后照常完成本地配置、模型目录、数据库和服务检查。

## 兼容与回滚

- 不包含数据库 Schema 迁移。
- 不改变 Provider、Workspace 或渠道配置格式。
- 如需回滚 npm 命令，可重新安装正式版：

```bash
npm install -g @hegenai/codexc@0.148.0
```
