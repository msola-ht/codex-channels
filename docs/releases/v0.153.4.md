# v0.153.4 正式版

`v0.153.4` 是 Codex Connect Gateway 对应 `codex-cli 0.153.4` 的正式版。它把 Gateway、生成协议、
App Server 合同与 npm 包统一到同一正式版本，并收录 0.153.4 升级后的渠道、Provider 和 WebUI 修复。

## 发布状态

- 发布类型：正式版
- Gateway 版本：`0.153.4`
- Codex CLI 与 App Server 协议：精确锁定 `0.153.4`
- Git Tag：`v0.153.4`
- npm 包：`@hegenai/codexc@0.153.4`
- npm 标签：`latest`
- GitHub Release：正式 Release

## 新增与改动

- `codexc setup` 增加 TUI 空闲总结和实验性上下文管理开关；前者默认关闭，后者仍按官方资格和默认关闭策略生效。
- 按模型统一自动压缩设置，并在会话完成卡片和模型上下文展示中使用对应模型信息。
- 保留 Codex 官方 Pinned 分区，移除 Gateway 自定义 Thread 分区管理；旧 `[thread_sections]` 配置会失败关闭，`/section` 返回迁移提示。
- 渠道会话达到配置的空闲阈值后自动解除绑定；无活动绑定时 Provider Client 可释放，后续请求会自动重连，且 Telegram、飞书和微信统一展示终态通知。
- WebUI 设置、管理确认、额度中心和用量趋势展示继续统一，OpenCode Go 的周末计费和完成卡片额度回退得到修复。
- Windows 源码安装、配置自动重启、输出队列取消和跨 Provider 思考等级跟随路径得到补齐或修复。

## 兼容与升级

- 必须使用精确的 `codex-cli 0.153.4`；旧 CLI 不受支持。
- 从 npm 安装或升级后，必须重启 Gateway 与全部 Provider App Server：

```bash
npm install -g @openai/codex@0.153.4
npm install -g @hegenai/codexc@0.153.4
codexc service restart all
codexc doctor
```

- 自定义 Thread 分区已移除。请改用官方 Pinned 分区的 `/pin` 与 `/unpin`；配置中仍存在
  `[thread_sections]` 时，Gateway 会拒绝启动并提示删除不受支持的配置。
- 本版本不复制上游 TUI、Plugin reconcile、异步用户问题、App Links 或活动 Turn 审批审查者切换等未纳入支持矩阵的能力。
- 不改变 Gateway 凭据文件和会话正文存储边界；安装 npm 包不会替换已经运行的进程。

## 发布边界

正式版必须在已合并且 CI 通过的 `main` 上按
[`Codex CLI 升级流程`](../codex-cli-upgrade.md#5-正式发布)执行：README 先同步正式安装命令，
再创建新的 `v0.153.4` Tag。npm Trusted Publishing 成功后才能创建同版本 GitHub Release；不得移动或覆盖已有版本的 Tag 与 npm 包。
